## v1.3.1 - 2026-11-26

**편집 화면 UI 통일 (가이드 양식 기준)**

### Changed
- **재생 막대 버튼** (`#transport`) — 가이드 시범 화면과 같은 양식으로 통일
  - 처음으로 · 정지 · 녹음: 원형 → 둥근 네모 (40px, 모서리 = 크기/3.2), 평평한 바탕 `#1b1d22` · 테두리 `#2a2c33`
  - 재생: 50px 노란 원 (`--accent`), 그라데이션 · 그림자 제거
  - 녹음: 빨간 테두리 제거, 아이콘만 빨간색
  - 크기는 `--tb` 변수 하나로 관리 (터치 42/52 · 모바일 30/36 · 가로모드 28/32)
  - 아이콘은 편집 화면(`app.js`) 아이콘 유지
- **색 통일** — `:root` 색 변수 · 창(`--win*`) · 글자색에 섞여 있던 누런빛 회색 61곳을 가이드와 같은 푸른빛 회색으로 교체 (`--text #e4e7ec`, `--muted #8b909a`, `--panel2 #1b1d22`, `--line #23252b` 등)
- **가이드 시범 화면** (`guide.js`)
  - 재생 막대의 글자 기호(⏮ ■ ●)를 편집 화면과 같은 SVG 아이콘으로 교체, 「● MIDI」 버튼도 아이콘 + 글자로
  - 위쪽 기능 버튼(`.gm-pill`)을 편집 화면처럼 어두운 바탕 + 노란 아이콘으로 (노란 바탕은 「켜짐」 표시와 겹쳐서)
- 스크립트 · 스타일 캐시 버스터 `?v=20261126u` (`edit.html` · `mypage.html`)

### Fixed
- 재생 버튼만 다른 버튼보다 아래로 처져 보이던 정렬 — 버튼 묶음(`.grp`)이 위쪽 기준 정렬이라 크기가 다른 재생 버튼이 어긋남 → `align-items:center`
- 재생 중 재생 버튼에 켜짐 표시가 안 보이던 문제 — `box-shadow:none!important`에 가려짐 → 노란 링 (`0 0 0 4px rgba(242,194,48,.25)`), 녹음 중에는 빨간 링 깜빡임

## v1.3.0 - 2026-11-26

**응애모드 · 전체 무한반복 · 로딩 화면 · 펜 미리보기**

### Added
- **응애모드** (`baby/`) — 칸을 톡톡 누르면 노래가 되는 아주 쉬운 작곡 모드 (Chrome Music Lab Song Maker 방식)
  - 멜로디 2옥타브 + 북 2줄(큰북 · 작은북), 누르기 · 끌어서 칠하기 · 지우기
  - 악기 4종(피아노 · 마림바 · 신스 · 플루트), 북 소리 4종(드럼 · 전자 · 나무 · 콩가)
  - 무한 반복(기본 켜짐) · 빠르기 60~180 · 되돌리기 · 길이 1~8마디 · 음계(도레미 / 펜타토닉) · 음 높이
  - 내 노래 저장 · 불러오기 · 지우기 (localStorage `tsl-baby-cur`, `tsl-baby-works`)
  - MIDI 내보내기 → 스튜디오 마이페이지 「불러오기」로 이어서 편집
  - iOS 스타일 UI (둥근 카드 · 유리 질감 하단 바 · 바텀 시트), 모바일 레이아웃, 다크 모드 자동
  - 별도 PWA로 설치 가능 (`baby/manifest.webmanifest`)
- **모드 전환** — index `#modes` 섹션 · 상단 버튼 · 설치 섹션, 마이페이지 「새 곡 만들기」 모드 선택 창, 편집 화면 설정 › 일반 「응애모드 열기」
- **전체 무한반복** — `Shift+L` / 하단 ∞ 버튼 / 모바일 더보기 메뉴
  - 곡 끝(마디 단위)에서 처음으로 끊김 없이 반복, 반복 구간(`L`)이 켜져 있으면 그쪽이 우선
  - 설정은 모든 곡에 공통 저장 (`hc-repeatAll`), 단축키 변경 가능
- **로딩 화면** (`loader.js`) — 페이지 진입 · 이동 시 로고 · 이퀄라이저 애니메이션 · 팁 문구 표시
  - `data-wait="1"`: 스크립트 로더 완료(`TSLoader.done()`)까지 대기 (edit · mypage)
  - `data-theme="light"`: 밝은 테마 (응애모드)
  - API: `TSLoader.show(text)` · `hide()` · `done()` · `go(url)`
- **펜 미리보기** — 펜 도구로 보드 위를 움직이면 노트가 생길 자리를 반투명 회색으로 표시 (노트 위 · Ctrl · 터치에서는 숨김)

### Changed
- **폴더 구조 정리** — 스크립트 `js/`, 스타일 `css/`, 변경 기록 `docs/` (HTML 진입 페이지 · `sw.js`는 루트 유지). 모든 HTML · 서비스 워커 · 로더 경로 수정
- 마이페이지 곡 그리드: PC 4열 (≤1100px 3열, 모바일 2열)
- 이모티콘을 모두 SVG 선 아이콘으로 교체 (응애모드 배지 · 악기/북 소리 · 설정 목록 · 악보 창 스피커 · 튜토리얼 문구)
- 서비스 워커 캐시 목록에 `loader.js` · `baby/` 파일 추가
- 스크립트 캐시 버스터 `?v=20261126r`

### Fixed
- 설정 창에서 「튜토리얼 / PC 튜토리얼 / 모바일 튜토리얼」이 열리지 않던 문제
  — `startTut`가 strict 모드의 블록 스코프 안에 있어 `ReferenceError` 발생 → `window.startTut`로 노출

## v1.2.0 - 2026-11-26

**믹서 · 오토메이션 · MIDI 도구 · 스템 내보내기 · 기능 가이드**

### Added
- 믹서(`X`): 트랙별 EQ · 컴프 · 리버브/딜레이 · 팬 · 볼륨 · 레벨 미터, 마스터 리미터 · 라우드니스(LUFS)
- 오토메이션(`B`): 볼륨 · 팬 · 밝기(필터)를 시간에 따라 선으로 그리기
- MIDI 도구(`N`): 코드 만들기 · 아르페지오 · 스트럼 · 레가토 · 잘게 나누기 · 역행 · 상하 반전
- 스템 내보내기: 트랙별 WAV를 ZIP 하나로 저장
- 노트 다듬기(`U`): 퀀타이즈 · 스윙 · 휴머나이즈
- 세기 레인(`V`): 노트 벨로시티를 막대로 보고 그리기
- 반복 구간(`L`) · 마커(`M`)
- MIDI 키보드 연결 · 연주 · 녹음
- 악기 30종 추가(총 79종), 악기 즐겨찾기 · 정렬, 트랙 설정에서 바로 악기 바꾸기
- 반주 스타일 20종 추가, 파트별 악기 · 패턴 · 옥타브 · 볼륨, 스윙 · 휴머나이즈
- 기능 가이드(`F1`): 기능별 시범 영상 · 각 창의 「사용법」 버튼

### Changed
- MIDI 불러오기 정확도 개선(`.kar` 포함), 마이페이지 전체 백업
- Thaniya Engine 안에서 열면 전체화면 버튼 숨김
- 창 디자인 통일 · 색 다듬기

### Fixed
- 긴 곡에서 반주 미리 듣기가 안 들리던 문제
- 편집 화면 일부가 깨지던 문제
