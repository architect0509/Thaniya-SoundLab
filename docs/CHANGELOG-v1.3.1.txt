Thaniya-SoundLab 업데이트 로그
========================================
버전 : v1.3.1
날짜 : 2026.11.26
요약 : 편집 화면 UI 통일 (가이드 양식 기준)


[바뀐 점]

1. 재생 막대 버튼
   - 처음으로 · 정지 · 녹음 버튼을 동그라미에서 가이드와 같은 둥근 네모로 바꿨어요.
   - 재생 버튼은 노란 원으로, 그라데이션과 그림자를 빼고 평평하게 맞췄어요.
   - 녹음 버튼의 빨간 테두리를 빼고 아이콘만 빨간색으로 남겼어요.
   - 버튼 안 아이콘은 편집 화면 아이콘을 그대로 써요.
   - 터치 화면 · 휴대폰 · 가로 화면에서도 같은 비율로 크기만 줄어요.

2. 색 통일
   - 창(설정 · 악기 · 반주 등)과 글자에 섞여 있던 누런빛 회색을
     가이드와 같은 푸른빛 회색으로 바꿨어요. (61곳)

3. 가이드 시범 화면
   - 재생 막대의 글자 기호(⏮ ■ ●)를 편집 화면과 같은 선 아이콘으로 바꿨어요.
   - 위쪽 기능 버튼(반주 · 다듬기 등)을 편집 화면과 같은 모양으로 바꿨어요.
     (노란 바탕은 편집 화면에서 「켜짐」 표시라서 헷갈리지 않게)


[고친 점]

1. 재생 버튼만 다른 버튼보다 아래로 처져 보이던 문제
2. 재생 중인데 재생 버튼에 켜짐 표시가 보이지 않던 문제
   - 이제 재생 중에는 노란 링, 녹음 중에는 빨간 링이 깜빡여요.
